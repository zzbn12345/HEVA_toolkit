# Prepare an annotation-only distribution

Source PDFs and DOCX files may remain local while annotations are versioned, provided the
package records:

- a source citation or documented non-findability reason;
- the source SHA-256 checksum;
- explicit rights for extracted text and annotations;
- curator acceptance of the exact candidate; and
- release membership and resource checksums.

Do not assume that permission to read a source grants permission to redistribute extracted
text. The current workspace validator expects local sources; a dedicated distribution
validation profile remains a planned refinement.

See [Approved export](../APPROVED_EXPORT.md) and
[Document metadata](../DOCUMENT_METADATA.md).
