# Review document colors

Every document has its own color configuration. Automatic suggestions preselect controlled
HEVA labels, but they remain pending until an annotator confirms every color or records why
a color should be ignored.

Model reasoning is retained as provenance and is not a fixed HEVA color definition.
Explanatory mapping text appears only when an explicit document legend supplied the
mapping.

See [Supervised document color mapping](../COLOR_MAPPING.md) for the complete contract,
batch-safety rules, and programmatic examples.
