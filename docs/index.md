# HEVA Toolkit

HEVA helps researchers turn color-annotated PDF and DOCX documents into validated, reusable
heritage annotation data.

These pages document the annotation app. Read them in order:

1. [Install and run HEVA](INSTALLATION.md)
2. [HEVA and validation](HEVA_AND_VALIDATION.md)
3. [What is a HEVA Data Package?](DATA_PACKAGE.md)
4. [Tutorial: inspect and repair an example](TUTORIAL.md)
5. [Limitations and extraction troubleshooting](LIMITATIONS_AND_TROUBLESHOOTING.md)
6. [Software design](SOFTWARE_DESIGN.md)

The dataset and benchmark have their own guides in the repository:

- [The HEVA dataset](https://github.com/zzbn12345/HEVA_toolkit/blob/main/data/README.md): the
  collections, spreadsheets and Data Packages.
- [The HEVA benchmark](https://github.com/zzbn12345/HEVA_toolkit/blob/main/benchmark/README.md):
  the two tasks, fixed splits, baselines, results and trained models.
